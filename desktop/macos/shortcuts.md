# macOS shortcut cheat sheet

⌘ Command · ⌥ Option · ⇧ Shift · ⌃ Control. `→` means “then”; `+` means press
together.

## Chrome

| Keys | Action |
| --- | --- |
| `⌘L → @tabs → Space → type` | Search open tabs |
| `⌘L → @bookmarks → Space → type` | Search bookmarks |
| `⌘L → @history → Space → type` | Search history |
| `⌘⇧A` | Search open tabs in a popup |
| `⌘L → type → Return` | Search or open a URL |
| `⌘F`, then `⌘G` / `⌘⇧G` | Find text, next / previous match |
| `⌘T` / `⌘W` / `⌘⇧T` | New / close / reopen tab |
| `⌘1`…`⌘8` / `⌘9` | Jump to a numbered / last tab |
| `⌘⌥←` / `⌘⌥→` | Previous / next tab |
| `⌘[` / `⌘]` | Back / forward |
| `⌘R` / `⌘⇧R` | Reload / reload ignoring cache |
| `⌘D` / `⌘⇧B` | Bookmark / toggle bookmarks bar |
| `⌘Y` / `⌘⇧J` | History / downloads |
| `⌘+` / `⌘-` / `⌘0` | Zoom in / out / reset |
| `⌘⌥I` | Developer tools |

[Address bar search guide](https://blog.google/products-and-platforms/products/chrome/search-your-tabs-bookmarks-and-history-in-the-chrome-address-bar/) · [Chrome shortcut reference](https://support.google.com/chrome/answer/157179?hl=en&co=GENIE.Platform%3DDesktop)

## Tinycast

| Keys | Action |
| --- | --- |
| `⌘Space → app or command → Return` | Launch an app or run a command |
| `↑` / `↓`, then `Return` | Choose and run a result |
| `⌘K` | Show actions and shortcuts for the selected item |
| `Esc` | Go back or dismiss |

File search and extensions need enabling in Tinycast settings. See the
[Tinycast documentation](https://tinycast.dev/docs/).

## macOS and Finder

| Keys | Action |
| --- | --- |
| `⌘Tab` / ``⌘` `` | Switch apps / windows of the same app |
| `⌘,` / `⌘H` / `⌘Q` | Settings / hide / quit current app |
| `⌃⌘Q` | Lock Mac |
| `⌘⇧5` / `⌘⇧4` | Screenshot controls / selected area |
| `Space` in Finder | Preview selected file |
| `⌘⇧G` / `⌘↑` in Finder | Go to folder / parent folder |
| `Return` / `⌘Delete` in Finder | Rename / move to Trash |
| `⌘C → ⌥⌘V` in Finder | Move copied files here |
| `⌘⇧.` in Finder | Show or hide hidden files |

[Apple shortcut reference](https://support.apple.com/en-us/102650)

## Paneru (this repo's bindings)

| Keys | Action |
| --- | --- |
| `⌥1`…`⌥4` | Switch workspace |
| `⌥⇧1`…`⌥⇧4` | Move window to workspace |
| `⌥←` / `⌥→` / `⌥↑` / `⌥↓` | Focus window in that direction |
| `⌥⇧←` / `⌥⇧→` | Move window left / right |
| `⌥V` / `⌥⇧V` | Cycle window widths forward / backward |
| `⌥F` / `⌥Space` | Full width / toggle floating |
| `⌥O` / `⌥T` | Stack / unstack |
| `⌥C` / `⌥N` | Center / move to next display |
| `⌥` + scroll | Step between columns |
| Four-finger horizontal swipe | Slide the window strip |

`⌘1`–`⌘4` select Chrome tabs; `⌥1`–`⌥4` select Paneru workspaces.
`⌘Space` opens Tinycast; `⌥Space` toggles a floating window. Paneru also uses
Option+arrow keys, which normally move by word in macOS text fields.
